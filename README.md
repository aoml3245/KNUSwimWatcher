# 경북대 수영 알림

경북대학교 체육진흥센터에서 선택한 수영반의 빈자리를 확인하는 macOS 메뉴 막대 앱입니다.

## 기능

- 메뉴 막대 물방울 아이콘에서 상태 확인
- 체육진흥센터 자체 계정 로그인
- 로그인 후 실제 수영반 목록 검색·선택
- 신청 사전확인 자동 처리(지병 없음·70세 미만·동의 항목)
- 신청 화면의 수영 옵션을 따라 반·시간별 실제 등록 목록 자동 로드
- 수영반 목록을 로컬에 저장하고 사용자가 새로고침할 때만 다시 로드
- 현재 인원·정원·잔여 인원을 서버 응답으로 표시
- 월~금·오전·검색어 조합 필터와 필터 결과 전체 감시/해제
- 신청 목록의 행별 스위치에서 감시 여부를 바로 변경
- 첫 확인의 빈자리와 이후 마감 → 신청 가능 전환 시 macOS 알림
- 감시 후보 중 첫 번째 가능한 반 하나만 가상계좌 방식으로 자동 접수
- 최종 요청 직전 재확인과 영구 신청 잠금으로 중복 접수 방지
- 신청 성공·실패·시도 여부와 무관하게 감시와 새 빈자리 알림 지속
- 1·3·5·10분 확인 간격
- 매월 19일 이전 자동 접속 방지
- macOS 로그인 시 자동 실행
- 즉시 확인, 알림 테스트, 신청 페이지 열기
- 통합 로그와 1 MB 단위 회전 파일 로그

비밀번호는 앱 설정이나 파일이 아닌 macOS Keychain에 저장합니다. 자동 신청을
명시적으로 켠 경우에만 가상계좌 접수 요청을 보내며, 실제 입금이나 카드 결제는 하지
않습니다. 센터 안내에 따라 접수 후 3일 이내 결제하지 않으면 등록이 유지되지 않을 수
있습니다.
수영반 탭의 목록은 한 번 불러오면 앱 재실행 후에도 저장된 내용을 사용합니다. 일정이
바뀌었을 때 사용자가 `새로고침`을 눌러야 전체 목록을 다시 조회합니다. 빈자리 감시는
이 목록 캐시와 별개로 선택한 강좌번호만 조회합니다. Keychain 비밀번호는 앱 실행 중
처음 한 번만 읽고 이후 검사에는 메모리의 값을 재사용합니다.

## 설치

완성된 앱을 `~/Applications/KNUSwimWatcher.app`에 설치합니다.

```sh
./script/install_app.sh
```

설치 후 메뉴 막대의 물방울 아이콘을 누르고:

1. `설정…` → `계정`
2. 체육진흥센터 아이디·비밀번호 입력
3. `저장하고 연결`
4. `수영반` 탭에서 필터를 적용하고 원하는 반의 감시 스위치 활성화
5. 필요하면 `감시` 탭에서 `후보 중 빈자리가 생기면 하나만 자동 신청` 활성화
6. `감시` 탭에서 알림 테스트와 자동 실행 설정

첫 알림 테스트 때 macOS가 알림 권한을 요청하면 허용합니다.

## 진단 로그

설정의 `감시` 탭에서 `로그 폴더 열기`를 누르거나 다음 파일을 확인합니다.

```text
~/Library/Logs/KNUSwimWatcher/watcher.log
```

로그는 최대 1 MB가 되면 자동 회전하며 최근 파일 3개를 보관합니다. 로그인 단계,
HTTP 상태, 응답 크기와 오류 유형만 기록하고 아이디·비밀번호·쿠키 값·페이지 HTML
원문은 기록하지 않습니다. 실시간 통합 로그는 다음 명령으로 볼 수 있습니다.

```sh
log stream --info --style compact \
  --predicate 'subsystem == "com.woni.KNUSwimWatcher"'
```

## 개발

```sh
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk \
  CLANG_MODULE_CACHE_PATH="$PWD/.build/module-cache" \
  SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/module-cache" \
  swift run --disable-sandbox --scratch-path .build KNUSwimWatcherSelfTest
./script/build_and_run.sh --verify
```

Codex의 Run 버튼도 `./script/build_and_run.sh`에 연결되어 있습니다.

## 제거

```sh
./script/uninstall_app.sh
```

앱은 복구할 수 있도록 휴지통으로 이동합니다. Keychain 비밀번호와 설정은 자동 삭제하지 않습니다.
